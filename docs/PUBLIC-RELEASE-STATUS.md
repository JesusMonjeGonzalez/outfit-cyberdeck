# Public Release Status

Status: **preview, version 0.1.0**.

The application is local-first and suitable for a public portfolio repository.
It is not a store release or a `1.0` product.

Still open before distributing packages:

- repository and UI tests;
- export and backup/restore;
- runtime checks on Android and Desktop;
- accessibility and narrow-layout verification;
- a third-party dependency and asset inventory for packaged distribution.
